# Vivaldi Spring Phone Test

This repository holds the scores and task records of a campaign on [Let's Encode](https://staging.lets-encode.mdw.ac.at/), where volunteers encode music together.

To take part, please use the [campaign page](https://staging.lets-encode.mdw.ac.at/test-20261007-test). Please don't edit files or open pull requests here directly: the campaign's automation keeps the scores and task records consistent, and it can only do that for work done through the campaign page.
